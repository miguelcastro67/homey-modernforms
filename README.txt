Modern Forms for Homey

Bring your Modern Forms smart ceiling fans into Homey with fast, reliable local control. Adjust fan power and speed, lighting, brightness, fan direction, and Breeze Mode directly from Homey.

Create powerful automations using Homey's Advanced Flow while the app stays synchronized with changes made from either Homey or the Modern Forms app. Communication takes place directly over your local network, with no cloud account, subscription, or additional bridge required.

Features

• Automatic discovery of compatible fans
• Local network communication (no cloud required)
• Fan On/Off
• Six fan speeds
• Fan direction
• Breeze Mode
• Light On/Off
• Light brightness control
• Automatic synchronization with the Modern Forms app
• Real-time state updates
• Advanced Flow Actions
• Advanced Flow Conditions
• Advanced Flow Triggers
• Duration-based Flow triggers

Why Local Control?

The app communicates directly with your fans over your local network.

Benefits include:

• Faster response times
• No cloud account required
• No subscription required
• Continues working even if the Internet is unavailable

Compatibility

Compatible with Modern Forms smart ceiling fans that support the Modern Forms local network API.

Installation

Install directly from the Homey App Store.
